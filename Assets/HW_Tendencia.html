TENDENCIA DE LA SERIE (SUAVIZADO EXPONENCIAL)


El modelo Holt-Winters, también conocido como Suavizado Exponencial Triple, descompone la serie considerando que el valor actual es un promedio ponderado de observaciones pasadas.

Valor Ajustado = nivel + tendencia + estacionalidad

A diferencia de los filtros estáticos, esta técnica utiliza tres parámetros de aprendizaje: Alfa (α) para el nivel, Beta (β) para la tendencia y Gamma (γ) para la estacionalidad. La tendencia en este gráfico representa la trayectoria suavizada que combina el nivel base y la pendiente calculada recursivamente.

Este método es superior para la detección de cambios estructurales recientes, ya que otorga mayor peso a los datos más nuevos sin perder la perspectiva histórica. El sistema selecciona automáticamente entre una tendencia Aditiva (cambios constantes) o Multiplicativa (cambios proporcionales) mediante el Griterio de Información de Akaike Corregido (AICc), asegurando el mejor ajuste estadístico posible.
